# ci-cd-final-project

## Project Overview

This project demonstrates a Continuous Integration and Continuous Delivery (CI/CD) pipeline using GitHub Actions, Tekton Pipelines, and Red Hat OpenShift.

## Technologies Used

- Python
- Git and GitHub
- GitHub Actions
- flake8
- nose
- Tekton Pipelines
- Buildah
- Red Hat OpenShift

## Pipeline Stages

1. Cleanup
2. Git clone
3. Code linting with flake8
4. Unit testing with nose
5. Container image build using Buildah
6. Application deployment to OpenShift
